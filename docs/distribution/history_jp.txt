QuickDiskBench - 更新履歴

v3.0.0（2026-09-19）
- プロジェクト構成を最新の quick-app-template (v2.0.0) 構成（src/, scripts/, docs/, dist/）に全面再編成。
- HTML・CSS・JS・画像を自己完結バンドルし、EXE内部リソース（RCDATA）へ直接埋め込み。外部 index.html なしでの単体起動に対応。
- Python試作実装を proto/ フォルダへ分離・整備。
- ビルドスクリプトを scripts/build.bat / scripts/build.py に移行、成果物出力を dist/ 直下に集約。
- コミット済みバイナリ（engine_x64.dll等）をGit管理から除外し、クリーンなビルドパイプラインを確立。

v2.2.1（2026-08-27）
- ヘルプ画面の作成者ワッペンを、バージョン情報タグから独立した別ダイアログに分離。
- ヘルプダイアログの「バージョン情報」ボタンを本文末尾から上部に移動。
- ツールバーの表示順を「回数→制限時間」から「制限時間→回数」に変更。
- ベンチマーク測定結果のテスト名列を140px固定幅にし、READ/WRITE数値表示エリアが余白なく残りのスペースを均等に使うよう変更。
- 既定ウィンドウ幅を900から720へ縮小。

v2.1.1（2026-08-17）
- 配布用ファイルをdist/binaryへ、説明書とライセンスをdist/documentsへ整理し、リリースZIPをサブフォルダなしのフラット構成に変更。
- ヘッダー右端の言語切替・CSV出力・ヘルプボタンを縦並びに変更、ヘルプダイアログ末尾に作者画像を追加。
- 既定ウィンドウ高さを900から780へ縮小。
- RND4K非同期I/Oの失敗・待機失敗・タイムアウトを成功扱いにしないよう修正。
- ランダムI/Oの安全タイムアウトを3秒から60秒へ延長し、低速・高負荷ドライブでの誤った0.00表示を抑制。
- 各テストの既定タイムアウトを60秒に統一し、--timeout / -TimeoutSecで最大3600秒まで延長可能に。
- GUIに制限時間選択（60/120/180/300/600秒）、I/O待機中表示、完了I/O数基準の進捗表示を追加。
- GUIのドライブ情報パネルにメーカー・機種、全テストの実計測時間を追加。

v1.0.0（2026-08-16）
- QuickDiskBench初回公開版。Windows向けGUI版とCLI版を提供。
- OSキャッシュをバイパスするDirect I/Oベンチマークを実装。シーケンシャルI/O、RND4K Q32T1、RND4K Q1T1の速度・IOPS測定に対応。
- 測定回数、書き込みスルー、CSV出力、全ドライブ測定スクリプトを提供。
- GitHub Releases向けのバイナリ配布ZIPを追加。

詳細な開発者向け変更履歴はリポジトリのHISTORY_jp.mdを参照してください。
